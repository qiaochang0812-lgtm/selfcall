# 沟通无限（NovaCustomerDialer）

Android 客户回访与连续拨号工具，应用名为“沟通无限”，代码包名 `com.example.novacustomerdialer`（仓库名 selfcall）。Kotlin + Jetpack Compose，minSdk 26，targetSdk 35，主要在华为 nova 10 上开发调试。

## 功能
- **首页**：今日工作台，优先展示到期回访和稍后回访客户，可直接拨打下一位。
- **客户管理**：搜索姓名/电话/单位；按状态和标签（可多选）筛选；导入、导出；批量改状态、批量标签、批量设回访日期、批量删除。
- **标签管理**：自定义标签及颜色。
- **连续拨号**：按全部名单/到期回访/稍后回访筛选；固定显示当前线路；上一位/下一位；通话结束后记录结果（可附备注、回访日期、标签），支持“保存并拨下一位”。
- **统计报表**：当天/当月沟通结果统计；授权通话记录后显示系统通话数据（拨出次数、接通次数、时长）。
- **设置**：拨号方式（系统默认、SIM1、SIM2、按拨号轮换）、轮换次数（1、2、3、5、10）、SIM/Telecom 账户检测、权限授权、字体大小、主题颜色。
- **沟通状态**：待联系、已接通、未接听、稍后回访、拒绝、已成交。
- 不申请网络、通讯录、短信或定位权限。

## 拨号与轮换
- 仅在用户点击拨号按钮后发起通话。
- 指定 SIM 时依次尝试：账户 ID 等于订阅 ID、ID 等于 ICCID（Android 8/9）、ID 中包含订阅 ID、系统返回顺序。仅靠“系统返回顺序”推测的映射不一定可靠，界面会标注“顺序推测”。**换到新机型后，请先用指定 SIM 拨打自己的号码，确认实际走的是哪张卡。**
- 轮换在通话界面真正接管前台后才计数；权限不足、系统拦截或 SIM 账户异常不会消耗次数。换卡按实际检测到的可用卡槽顺序循环。
- 部分系统（小米/OPPO/vivo 等）可能对第三方应用直拨电话弹出确认或把权限默认设为“询问”，需在系统权限管理中改为允许，否则连续拨号会被打断。

## Android 权限
- `CALL_PHONE`：点击拨号后直接拨出电话，指定 SIM 时必需。
- `READ_PHONE_STATE`：读取活动 SIM 和通话账户，用于映射 SIM1/SIM2，指定 SIM 或轮换时必需。
- `READ_CALL_LOG`：可选；用于匹配客户最近通话并生成统计。拒绝授权时相关显示为空，其他功能不受影响。

## 导入导出格式
```csv
姓名,手机号,备注
张三,13800138000,续约回访
李四,+8613900000000,新客户
```
- 支持 CSV 和 XLSX；CSV 可为 UTF-8（含 BOM）或 GBK，支持引号内的逗号和换行；XLSX 读取全部工作表。
- 识别的列：姓名、手机号（含多个电话列）、单位名称、备注、状态、下次回访日期、标签（用 `|` 或 `;` 分隔）、最后沟通；也兼容企业查询导出表（企业名称 + 多个联系电话，每个号码生成一条记录）。无表头时按“姓名、手机号、单位、备注”的位置识别。
- 号码保留开头的 `+`；同一号码带或不带 86 前缀视为重复，已存在的号码会跳过。
- 回访日期支持 `2026/11/2`、`2026年11月2日` 和 Excel 日期序列号，统一转换为 `yyyy-MM-dd`。
- 单次最多读取 200000 行。导出文件为带 BOM 的 UTF-8 CSV，可直接用 Excel 打开。

## 数据存储
客户数据保存在应用私有目录的 `customers.json`（后台原子写入），首次启动会自动从旧版 SharedPreferences 迁移，旧数据不会被删除；标签和设置保存在 SharedPreferences。应用关闭了系统备份，卸载或清除应用数据后数据会丢失，请定期在客户管理页导出备份。

## GitHub Actions 编译
每次推送到 `main`/`master`，或手动运行 Actions 中的 **Build Android APK**：
1. 若仓库根目录有上传的源码 zip：解压并覆盖到工作区（不覆盖 `.github`，其中的工作流文件需要手动更新），并在日志列出变更文件。
2. 运行单元测试（失败只提示，不阻断出包）。
3. 使用仓库 Secrets 中的签名密钥构建 release 包：`KEYSTORE_BASE64`、`KEYSTORE_PASSWORD`、`KEY_ALIAS`、`KEY_PASSWORD`。缺少密钥时构建直接失败，不会回退到调试签名。日志会打印 keystore 与 APK 的证书 SHA-256，可与自己的 keystore 对比。
4. 上传产物 `NovaCustomerDialer-release`（`app-release.apk`）。release 已开启 R8；如遇运行异常，可把 `app/build.gradle.kts` 中的 `isMinifyEnabled` 改为 `false`。
5. 构建并上传成功后，才把覆盖结果提交到仓库并删除根目录的 zip（提交带 `[skip ci]`）。构建失败时仓库不变、zip 保留，修复后可直接重试。该步骤要求仓库开启 Settings → Actions → General → Workflow permissions → **Read and write permissions**。

下载方式：GitHub 仓库 → Actions → 选择成功的运行 → Artifacts。覆盖安装要求签名密钥与已安装版本完全一致。

## 本机编译
需要 JDK 17、Android SDK（API 35）和 Gradle 8.9：
```bash
gradle -PstandaloneDebug=true assembleDebug
```
输出：`app/build/outputs/apk/debug/app-debug.apk`。`standaloneDebug` 沿用正式 applicationId，但使用本机调试签名，**不能覆盖安装 CI 签名的 release 包**（会提示签名不一致）；不传该参数时调试包带 `.debug` 后缀，可与正式版共存。

## 说明
- 当前是可编译的原型，不保证在所有品牌和系统版本上表现一致。纯血鸿蒙（HarmonyOS NEXT）不能安装 APK。
- 应用启用边到边显示（targetSdk 35 在 Android 15 上强制），顶栏会避开状态栏。
- 请仅联系有合理联系依据、允许联系的客户，控制联系频率，并遵守当地电话营销和隐私法规。
